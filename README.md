# **About Me**

### *Software development with an end-to-end mindset.*

</div>

<br/>

I’m **Md. Akibul Hasan Arman**, a **Computer Science & Engineering graduate from Bangladesh** with hands-on experience across **full-stack web development, backend systems, database-driven applications, machine learning, computer vision, and business intelligence**.

My recent work includes a **Next.js + ASP.NET Core + PostgreSQL academic workflow platform**, a deployed **Next.js + Supabase movie platform**, a motion-focused commerce experience, role-based applications, PHP/MySQL business systems, computer-vision research, Flask dashboards, and an end-to-end retail data warehouse.

I enjoy working beyond the surface of an application. I’m especially interested in how the **frontend, API, authentication, authorization, database structure, business rules, testing, deployment, and data flow** fit together as one complete system.
